## 0.0.1

* Initial Android implementation for Newpos Q-series internal thermal printers.
* Added AIDL integration with the vendor IPOS printer service.
* Added support for text, formatted text, columns, images, QR codes, barcodes, raw bytes, ESC/POS commands, and paper feed.
* Added printer status event stream with paper-out detection.
* Added example app with printer diagnostics and test actions.
